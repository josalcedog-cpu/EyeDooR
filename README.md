# Requerimientos del proyecto (2 de diciembre de 2025): 

# Camara(ESP32-CAM):
La red de que este conectada a la camara debe ser la de Antonio a 2.4GHz y los puertos de redes deben estar separados (camara:80, capture:81, servidor flask: 5000)

# Timbre Pulsador: 

El pulsador debe estar conectado a la red de Daniel Salcedo en 2.4GHz pin D4.

# En la parte de python - flask se necesita instalar en la terminal:

- pip install flask firebase-admin werkzeug requests

# En la parte de Arduino - ESP32 se necesita instalar en la IDE de Arduino:

- Instalación: Sketch > Incluir biblioteca > Gestionar bibliotecas > Buscar "Firebase ESP32 Client" by Mobizt
- Instalación: Herramientras > Placas > Gestor de placas > "esp32" by Espressif Systems
